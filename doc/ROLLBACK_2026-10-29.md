# Rollback to the build before the white-screen work (October 29)

The game felt worse after the white-screen investigation: textures, the
mouse and aiming, and frame pacing. The code under `tools/`, `Launch-KIU.cmd`
and `README.md` are back to commit `ecc598d` (October 24, "Keyboard
movement: instant in flight..."), the last build before that work, exactly,
60 FPS mode included and switched on, to be played first; the white-screen
correction then starts again from this build.

## What caused the white screens

The old 60 FPS mode ran the game's logic twice as often. With it off the
white after warps (chapter 9, Pandora) went away (confirmed October 28), so
it is a 60 FPS bug: something in the game counts updates and fires twice.
That is what to correct next, in this mode, rather than replacing the mode.
